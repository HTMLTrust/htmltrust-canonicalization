HTMLTrust independent-JS conformance -- browser (DOMParser) runner

This page runs the same conformance/PROTOCOL.md fixtures as conformance-runner.mjs, but through the browser's own HTML parser (a detached <template> element's innerHTML setter, fragment context; see adapters/browser-domparser.js) instead of parse5, exercising canonicalize.js's engine-agnostic algorithm on a second, independent HTML parser. It fetches fixtures from conformance/fixtures.sha256 and conformance/fixtures/… relative to this file, so it must be served, not opened as a file:// URL: from the repository root run python3 -m http.server 8000 and open http://localhost:8000/independent/javascript/browser-runner.html. Every fixture body is hashed with crypto.subtle.digest and checked against fixtures.sha256 before any of them run, the same integrity guarantee --verify-fixtures gives the Node runner; a mismatch aborts the run with an error rather than a silent pass/fail count.
